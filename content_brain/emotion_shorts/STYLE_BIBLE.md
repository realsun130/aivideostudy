# AI 情感动画创作体系 V1.0

定位：30—60 秒竖屏动画；生活细腻型、现实刺痛型、荒诞幽默型。核心命题：**把普通人说不出口的情绪，变成看得见的小故事。**

## 1. 创作原则

- **行为先于情绪标签**：先有「把一双拖鞋往边上挪」「发语音又撤回」，再谈孤独、依恋、羞耻。
- **矛盾先于主题**：角色必须同时有两个成立、却互相妨碍的愿望。
- **道具先于金句**：一个可复现的动作或道具，比「我们终将明白」更有力量。
- **节制的完成度**：结局不必反转、和解或治愈；可以留下不舒服的余味。
- **拒绝虚假真实**：未经核验的网络片段、AI虚构情节不得标成“真实故事改编”。
- **情绪类型多样**：温暖、尴尬、难堪、犹疑、恼怒、荒谬、惭愧，都可以是好的结尾；不要把所有故事写成催泪视频。

## 2. 三种风格的写作语法

### A. 生活细腻型

- 核心结构：常态细节 → 微小缺席/偏差 → 人物下意识动作 → 观众自行认出情绪。
- 关键道具：筷子、开关、聊天框、旧地址、座椅、外卖备注。
- 不使用重大事故、绝症、突然失联来补足戏剧性；不用角色解释自己的心理。
- 评价问题：最后五秒的行为，让前面的某个细节产生了新意义吗？

### B. 现实刺痛型

- 核心结构：两个合理诉求 → 资源/时间/规则冲突 → 一方做出并不体面的选择 → 留下代价。
- 不写纯粹坏人；不要把结构性困境简化成一句“多沟通就好了”。
- 评价问题：双方是否都有道理？无论怎样选择，是否都有人付出真实代价？

### C. 荒诞幽默型

- 核心结构：把生活隐喻字面化 → 为世界设定一条可理解的荒诞规则 → 规则连续升级两次 → 小动作戳破荒谬。
- 只设置**一条**核心怪规则；主角的反应要像真人。
- 评价问题：去掉夸张设定，现实生活中是否真的存在这种心理或处境？

## 3. 素材挖掘：不搜“感人故事”，搜行为与矛盾

**输入渠道与建议比例（起步试验，不是事实上的最优值）**：

1. 40% 本人/团队主动观察：每天两分钟记录3个瞬间（看见谁做了什么、说了什么、有什么违和感）。
2. 30% 自愿提供的匿名生活故事或获得许可的访谈：每周3—5次10分钟访谈，询问具体行为而非抽象感受。参考 StoryCorps 的开放式人生访谈提问方法。
3. 20% 平台公共讨论的**主题观察**：从小红书、知乎、豆瓣、B站、短视频评论中发现反复出现的处境，不复制可识别私密内容、私信或原文；注意平台条款和合规采集。
4. 10% 原创的设定实验：从已观察到的心理矛盾出发创造动画化隐喻，单独标记为“原创虚构”。

**访谈具体提问**：
- 最近一次你说“没事”，实际上心里不舒服，是在什么场景？
- 有没有一件你总做，但别人不知道为什么的事？
- 你有没有因怕别人为难，而说出与真实愿望相反的话？
- 哪一条微信，你打了很久最后没有发？
- 最近有什么事，让你同时觉得好笑和难过？
- 那次发生时你手里拿着什么，房间里有什么声音？

**素材卡（最小记录单元）**：
```yaml
id: LM-0001
scene: "晚上十一点，厨房只剩抽油烟机的响声"
observed_behavior: "手机输入框里写了‘我今天真的很累’，又删成‘晚安’"
exact_words: ""
visible_object: "亮着的手机屏幕、没洗的碗"
apparent_goal: "维持气氛，不让对方担心"
hidden_need_hypothesis: "希望被察觉和照顾"
conflict: "想被关心，但不愿主动索取"
source_type: "自我观察/授权访谈/公共主题观察/原创虚构"
source_date: ""
source_reference: "内部链接或可追溯编号；不要放私人身份信息"
consent_or_usage: "需核验"
privacy_notes: "去身份化、去识别细节"
confidence: "观察到的事实/采访者陈述/创作者推断"
```

## 4. 故事竞争与筛选

每次先聚类 20—30 张素材卡，形成 8—12 个不同故事方向（禁止只有结局变化的同构剧情），初筛保留 3—4 个，人工终选 1—2 个；评分只是对比工具，不能替代人的判断。

评分满分 100 分：
- 具体、可信的行为细节：25
- 人物愿望与心理矛盾：20
- 新颖但不刻意的切入：20
- 能否由画面而非旁白表达：15
- 30—60 秒结构完整性：10
- 可制作性与伦理风险：10

**硬性否决**：素材来源不明且需要冒充真实；关键人物行为靠作者解释才成立；完全依赖灾难/死亡强迫煽情；角色沦为“坏妈妈/坏上司”符号；20秒以后才看得懂主角处境；与已发布/已入库选题高度同构；私人经历未经许可披露；无法通过角色动作或环境声理解故事。

**反套路审稿六问**：
1. 把所有画外旁白删掉，情绪还存在吗？
2. 把结尾金句删掉，故事还成立吗？
3. 角色有没有一点不太体面、却可以理解的自私？
4. 第一秒的细节与最后一秒是否有关联？
5. 观众是否能提前十几秒猜到唯一结局？（预测到不必直接否决，但要检查剩下还有没有新的观察）
6. 作品是否在试图教训观众，而不是展示一个值得他们自己判断的情境？

## 5. 四类 Agent，六个门槛

1. **采集/整理 Agent**：把授权材料、第一方观察、公共讨论主题制成素材卡；不能添写虚构的“真实细节”。门槛：出处、可用性、具体动作三项齐备。
2. **情绪洞察 Agent**：每张素材提炼两个并存诉求，输出若干不同的心理矛盾假设并标注哪些只是推测。门槛：有不依赖重大事件的真实冲突。
3. **选题编辑 Agent**：对候选故事盲评去重、淘汰同构桥段，按三类风格筛选。门槛：每批至少三种不同情绪，不可全是父母亲情或“理解与和解”。
4. **编剧 Agent**：每题先给3种不同叙事机制，再选1个写成30—60秒分镜；每镜头写可见动作、道具、情绪信息、环境声。门槛：不超过2个主场景、3个主要人物、通常6—9镜头；尽可能不依赖口型与复杂肢体动作。
5. **苛刻审稿 Agent**：对真实性、情感操控、台词、动作负担、隐私和版权做红队检验；提出删减，而不是套话建议。门槛：必须指出至少一个潜在弱点，允许“这篇不值得拍”。
6. **小样测试与复盘**：草图/静帧/纸片动态样片给5—10名目标受众测试。记录复述率、假感位置、联想到的个人经历、想分享给谁及原因、完成观看率；正式发布后再对比留存、完播、分享、收藏以及真实评论情绪。门槛：依据观众反馈回写故事 DNA，不只优化点击率。

## 6. 单条视频生产规格（初始预算）

- 默认竖屏 9:16；30—60秒；人物 1—3；主场景 1—2；约 6—9 个镜头。
- 视觉：手绘平面、纸片定格、简约剪影都可以；优先利用表情静帧、手部特写、道具移位、环境变化、慢推拉，不追求复杂连续动画。
- 旁白原则：可以有，但不能告诉观众角色已经用动作表现出来的情绪。
- 开头0—3秒：生活动作或怪规则，不必强行制造危言耸听的“钩子”。
- 5—35秒：让角色用至少两个动作暴露矛盾；避免信息堆砌。
- 35—55秒：用一个物件、行为或规则的变化形成余味。
- 片尾：允许留白，拒绝统一的“人生道理字幕”。

## 7. 试运行：两周小批次（建议而非硬性节奏）

- 第1—2天：整理50张行为素材卡，核查来源，去重。
- 第3天：生成12个互不相似的故事种子，三风格各4个。
- 第4天：评分选出6个，人工选3个。
- 第5—7天：3个分镜剧本，6—9镜头/篇，低成本静帧样片。
- 第8—10天：真实观众盲评并修订，挑1—2支成片。
- 第11—14天：发布或内部验证，建立复盘基线。

> 试验重点不是“每周必须产出多少”，而是测出三个风格中哪些内容既有真实反馈、又能低成本稳定制作。**每个风格至少做两次试验后，再考虑规模化。**

在 `D:\aivideotest` 下建立 `content_brain\emotion_shorts\`，建议包含：

```

  LIFE_MOMENTS.md

  STORY_DNA.md
  SCRIPT_REVIEW.md
  CURRENT_STATE.md

  scripts/
  tests/
```

**状态管理**：日常让 Agent 只读 `CURRENT_STATE.md`、本次涉及的候选素材卡、对应风格规则、最近一轮评审报告；不重复携带整段聊天记录。项目文件写入前先确认路径和已有版本，别覆盖既有内容。

## 9. 发布合规备注（中国平台）

- 访谈收集与使用应有明确授权；公共帖子/评论也不能默认无限制可复制、可公开或可批量抓取。公开个人信息的处理仍受到个人信息保护法等规则约束。
- 对合成图片、声音和视频，按发布时平台规则及中国《人工智能生成合成内容标识办法》处理标识。该办法自2025年9月1日起施行。
- 保留创作来源与素材权利记录；不要把合成或拼贴内容标成可核验的当事人实录。
