## 线条与材质

- **线**：可变粗细、潦草、多层修正笔触（construction 红棕 + contour 暗红褐）。  
- **填**：半透水色毛块，alpha 约 0.35–0.72。  
- **影**：交叉线，不是干净矢量渐变。  
- **颗粒**：中等纸噪；近灯尘埃粒子默认关，可按 JSON `particle_params` 开。

叠层画出的发卡 / 灯 / 手机轮廓必须说同一种「素描话」，禁止突然变成精修矢量描边。

## 灯光配方（本帧护城河核心）

| 项 | 设定 |
|----|------|
| Key | **猫爪灯** practical，径向暖光，原点约归一化 `(0.88, 0.42)` |
| Fill | 手机侧弱冷边，强度 ≤ Key 的 ~25% |
| Ambient | 极低（~0.08），近黑 |
| 可调参数 | `paw_lamp_intensity` 默认 `1.0`，动画建议 `0.85–1.12` 缓脉冲 |

**规则**：可读性几乎全靠爪灯覆盖画面；禁止再加电影级左侧硬光。

## 图层契约（简表）

```
z0  暗墙/纸洗          静
z1  墙照合影           静；子槽：粉发卡 / 黑领结
z2  床头柜·枕·被暗部   静
z3  缅因（V8 锁定）    微表情 only · 禁止椭圆重画
z4  查理王（锁定帧）   下颌/耳次动 · 禁止椭圆重画
z5  粉耳发卡 · 爪灯    代码叠层优先
z6  手机背面           代码叠层 + 朝向锁
z7  碎屑/动势记号      可选
```

**Edit Lock**：只改具名参数；未点名像素保持锁定底图。

## 可编辑参数（给合成器 / Remotion）

| 参数 | 默认意图 | 失败条件 |
|------|----------|----------|
| `ear_bow` | 查理王右耳根（镜头左）粉色可见 | 改发卡却动了缅因胸或灯 |
| `photo_bowtie` | 合影缅因胸前**黑**领结 ROI | 用生图模型在 ROI 里瞎补 |
| `live_maine_chest_bowtie` | **默认 false**（床上缅因无胸前领结） | 无请求却长出领结 |
| `phone_back` | 背面朝镜头；模组朝床头上 | 翻成屏幕朝镜 |
| `paw_lamp_intensity` | `1.0` | 灭主光或改成冷光主调 |

手机产品话术：

> **玩手机** = 看得见脸 + 看得见**手机背面**。

## 质量门禁（合不合格）

**必须**

- 角色来自锁定帧，不用椭圆代码体冒充最终角色  
- 猫爪灯仍是主光  
- 手机朝向锁成立  
- 具名修改不串改无关道具  

**直接判失败**

- 为改配件整图重跑图像模型  
- 床上缅因无故出现胸前领结  
- 手机变成屏幕朝镜头
