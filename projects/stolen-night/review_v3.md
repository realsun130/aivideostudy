# 《偷来的夜》v3 四方独立评审 ⚠️ 待测试

评审对象：`storyboard_v3.md`（90s / 14 镜，无对白无字幕）。  
规则：评审 1–3 只指出问题、不给改法；评审 4 可提简化建议。各评审互不参考对方意见。

---

## 评审 1｜动画导演（节奏、镜头、调度、声音）　6.5 / 10

1. **镜头 9→10→12 的倒计时时间轴自相矛盾。** 镜头 9 弹出「5 秒后播放下一集」并开始滴答；镜头 10（8s）写倒计时声断；镜头 11 又占 7s；镜头 12 却写「倒计时到 2」。中间至少空了十多秒，数字不可能还停在 2。高潮段最重要的声音钩子自己裂了。
2. **镜头 3 在 6 秒内塞了四拍情节。** 发送纪要 → 新消息「再改一版」→ 回「好的👌」→ 切短视频。竖屏下气泡文字几乎读不完，后半「切短视频」会糊成一闪；报复动机写进了台本，调度上观众未必跟得上。
3. **镜头 4→5→7 情绪台阶仍平。** 4 与 7 都是「刷手机 + 小光被忽视」，中间只隔窗外灭灯（6）。笑点（5）有效，但笑完立刻回到同一种忽视，没有新的视觉压力，7 的 7 秒推镜会显拖。
4. **镜头 1 仍过载。** 6 秒内：进门、工牌、掏橘放柜、小光蹦出。橘子比上版清楚，但工牌几乎没有停留帧；门口全景里工牌字样在手机竖屏上基本不可读。
5. **镜头 13 只有 4 秒，却要完成「窗景暖橙确认 → 黑场 → 鸟鸣先入」。** 暖光刚立住就切黑，「小光还在」的视觉确认偏短；黑场若小于 1 秒，J-cut 会像硬切而不是呼吸。
6. **镜头 14 的 12 秒内部节奏未标切点。** 「阳光 / 剥橘 / 抽屉连震 / 看一眼 / 继续剥 / 放一瓣 / 淡出」挤在一条中景长镜里。震动若出现太晚，前半是氛围广告；若太早，后半只剩剥橘空镜。全片第二重要的音效（闷震）没有被写出独立的安静窗口。

## 评审 2｜编剧（动机、选择、代价、伏笔回收、原创性、主题）　6.5 / 10

1. **代价仍偏轻，选择可逆。** 按灭屏幕、把还在充电的手机放进鞋柜抽屉——她放弃的是「下一集倒计时」，具体且好懂，但抽屉随时能开，物理与情感代价都有限。观众很容易读成一次自制力小胜，而不是不可逆的转折。
2. **镜头 3「再改一版」没有在结尾回收。** 全片最强的当代动机钩子停在前 15 秒；镜头 14 抽屉闷震只标注「工作群」，没有视觉或信息确认它是否就是同一条改稿线。伏笔半悬，主题「偷来的夜」与「白天」之间缺一根钉子。
3. **主题仍容易滑向「别带手机上床」。** 15:30 阳光是时间标签，她在白天没有完成一个主动、属于自己的动作，只是窗边剥橘。原稿洞察「把属于自己的时间放进白天」仍停留在光效，没有落到行为。
4. **情感中心仍在小光，不在她。** 10–11 捧起微光是全片最柔的两镜；她的胜利（灭屏、关抽屉）被写成手续，心疼点继续落在精灵回亮，而不是「她从工作手里抢回又亲手放下的那点自由」。
5. **倒计时作为「被放弃之物」的设定被时间轴写坏。** 若 9–12 的数字逻辑不成立，「她放弃的是下一集」这层代价在观众端会失效或变成穿帮。
6. **原创性中等。** 「深夜追加工作消息 + 好的👌 + 切短视频」是这版最贴当代的一笔；发光小精灵代表被冷落的自我，仍是短视频/广告常见形象。橘子弧线已完整（1 种下 → 14 分给小光），但不足以撑起角色辨识度。

## 评审 3｜普通观众（25 岁，一线城市独居上班族）　6.5 / 10

1. **整抽屉关上有点假正经。** 手机放进自家鞋柜我不再担心被偷，但现实里我最多扣枕下或翻面；整部抽屉一关，会像在拍教我自律的片子，出戏半秒。
2. **心疼的还是小光，不是我。** 柜底橙光、捧起来那一下会软；可想到自己时，疼点该是「好不容易偷来的夜晚全刷没了」，片子更多在心疼那个光团。
3. **「好的👌」段太短、字太多，怕看不清。** 这本该是最戳我的瞬间，6 秒里冒两条工作消息再切视频，刷短视频的速度下我可能只抓住表情包，抓不住「再改一版」。
4. **结尾偏顺，像周末广告。** 周日下午阳光、剥橘子、放一瓣给小光——美，但完结太干净。抽屉震两下她看一眼再剥，有一点真，仍不够「我明天大概率还会这样」。
5. **划走小光会笑，但记不住到第二天。** 笑完立刻又是她刷、小光暗，像被教育，笑点没有换成对我自己的刺。
6. **会不会转发？** 犹豫。可能转，配文多半落在「好的👌」或柜底一眼，而不是结尾阳光；没有一句能让我直接配「这就是我昨晚」的刺点。

## 评审 4｜代码动画技术负责人（Remotion / 2D 程序化，无图生视频）　7.5 / 10

相对可推版本：门外开门六连动作已去掉；镜头 8 已拆短镜；整体可做性上升。新风险集中在 UI 可读性与高潮手部/抽屉。

| 镜 | 风险 | 备注 |
|---|---|---|
| 1 | 中 | 进门 + 掏橘 + 小光蹦出，事件仍多 |
| 2 | 低 | 锁屏插入，字号需 ≥ 画面高约 3% |
| 3 | **中高** | 两条消息气泡 +「好的👌」+ 切短视频，6s 内 UI 可读性是硬约束 |
| 4 | 中 | 手影小狗形变 |
| 5 | 低 | 划屏整体平移 |
| 6 | 低 | 窗灯布尔开关，最适合程序化 |
| 7 | 低–中 | 亮度/蓝橙插值；人物可少动 |
| 8 | 中 | 脚入画 + 小光滚动；保持两刀切，不做完整走路 |
| 9 | 低 | 充电 UI + 倒计时字 |

| 14 | 中 | 剥橘手部；同机位复用镜头 1 场景组件 |

**主要问题与简化建议**

1. **镜头 3 是新的最高信息密度镜。** 建议拆成「发送 / 新消息特写 / 回复+切视频」两到三刀，或气泡只保留关键词放大，否则竖屏必糊。
2. **镜头 8 保持「脚入画 / 滚出画」两短镜**，小光滚动用「位移 ÷ 半径」驱动旋转，不做全身踢腿。
3. **镜头 12 用侧面固定机位**：只拍手 + 抽屉缝 + 蓝光消失，不做全身起立走动。
4. **镜头 11、14 手部**：3–4 个关键姿态切换；剥橘改成「已剥开的橘子 + 掰下一瓣」单动作。
5. **全局复用**：镜头 1/14 同机位、6/13 同窗景，必须共用场景组件加参数（亮度、时段、窗光），可省约三成背景工时。
6. **倒计时跨镜（9–12）**：无论戏剧怎么改，技术侧应把倒计时做成单一时间源参数，禁止分镜各写各的数字，否则渲染时必穿帮。

## 综合

### ≥2 位评审一致的问题

- **倒计时时间轴（9→10→12）逻辑破裂**（导演、编剧、技术）：高潮代价钩子自身穿帮。
- **代价仍偏轻 / 选择可逆 / 结尾偏顺**（编剧、观众）：抽屉可开、「下一集」不够疼、阳光剥橘像广告。
- **镜头 3 信息过载**（导演、技术、观众）：报复动机写进了台本，调度与 UI 跟不上，最戳的瞬间可能看不清。
- **情感中心仍偏小光**（编剧、观众）：心疼光团多于心疼她/自己。
- **镜头 1 仍挤**（导演、技术）：工牌停留不足。
- **镜头 3「再改一版」未在 14 回收**（编剧；观众侧表现为结尾缺刺点）：最强当代钩子半悬。

### 冲突点

- **抽屉方案的可信度**：观众承认「比门外可信」，但又觉得「整抽屉有点假正经」；编剧认为可逆导致代价轻——空间问题已解决，力度问题未解决。
- **倒计时要不要在镜头 12 再出现**：导演嫌与时间轴矛盾且易抢戏；编剧认「放弃下一集」是具体代价——含义可留，数字跨镜写法必须先自洽。
- **分数结构**：技术 7.5 最高（可做性好），导演/编剧/观众同在 6.5——工程可推进样条，戏剧仍未锁版。

### Top 3 必改

1. **先修镜头 9–12 倒计时时间轴**，否则「放弃下一集」这层代价在成片里不成立。
2. **加重选择的代价或不可逆感**（现在的抽屉方案可信但太轻），并避免结尾读成自律公益广告。
3. **回收镜头 3 的「再改一版」**（或让镜头 14 的震动钉死同一条工作线），同时给镜头 3 减负，让动机真正被看见。

### v2 三处必改落地检查

| # | v2 必改 | v3 是否落地 | 说明 |
|---|---|---|---|
| 1 | 镜头 14 隔门震动 vs 12% 电量过夜（诱惑为假） | **已落地** | 手机进室内抽屉且保持充电，周日下午闷震物理上成立。 |
| 2 | 镜头 11 放门外 / 双鞋柜混用 / 会被偷 | **已落地** | 改为室内鞋柜抽屉，公共走廊风险与道具混用去掉。 |
| 3 | 镜头 2 松气抽掉「报复性熬夜」动机 | **已落地（动机层）** | 镜头 3「再改一版」+「好的👌」+ 切短视频，引擎回来了；但 6 秒过载 + 结尾未回收，动机「写进了」却未「钉死」。 |

**总判**：v2 的三处硬伤已修好；v3 的新瓶颈是「倒计时穿帮 + 代价偏轻 + 最强动机未回收」。不建议无修直接锁版。
