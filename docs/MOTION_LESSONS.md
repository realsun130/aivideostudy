# 动效经验文件（Motion Lessons）

来源：Florence @flxrnc《Opus 5.5 Motion Lab》（X 文章，2026-10）。适用于 Bot B（分镜）、Bot D（程序化成片）、Bot E（审核）。

## 0. 总原则
- 模型写代码画像素：每帧 = f(t)。时间只来自帧号，禁用系统时钟/计时器；随机必须设种子。
- 形容词 → 数字。每个形容词替换成数字，就是从模型手里拿回一个决定。
- 不信“一句提示出片”：正常是首版 + 2–4 轮带帧号修正。

## 1. 渲染合同（贴在每个动效任务下）
- 画面只由 frame/fps 决定；不读 Date.now / requestAnimationFrame 计时。
- 所有随机 seeded；同一帧渲两次必须像素一致。
- 循环片只渲 0..N-1，不渲 N；周期用 phase = frame/N，整数圈。
- 支持 `?t=秒` 或 `?frame=N` 冻结任意帧；迭代期显示帧号角标，终版关闭。
- 修好一个坑就把规则追加到本节。

## 2. 导演式提示模板（Bot B 输出 / Bot D 输入）
GOAL（一句话：观众感受/动作） → TIME（fps、总帧数、画幅） → SHOTS（每镜：帧区间、一个主动作、交接方式：默认硬切，转场必须是决定） → STYLE LOCK（不可变项，如角色比例、配色） → BAN LIST → QA（先出静帧再全片）。
- 一镜一主角动作；次要动作幅度 50–70%、晚 100–200 ms；环境动作 <5%、慢正弦、不停。
- 起始禁用清单：紫/蓝渐变、光晕、镜头光斑、装饰粒子、全体同时淡入、每个元素都淡入上滑、全部居中、阅读中移动的文字。首版渲完后点名补充新出现的默认样式。

## 3. 数字速查
- 缓动：入场 ease-out，出场 ease-in 且短 40–50%；跨屏移动 ease-in-out；线性只用于旋转/进度/循环相位。
- 弹簧阻尼比：1.0 不弹；0.7–0.85 高级；0.4–0.6 活泼；<0.3 卡通。位置/尺寸可弹，透明度/颜色不弹。Remotion 默认 spring ≈ 0.5。弹簧用解析式，可单帧求值。
- 时长：UI 反馈 100–200 ms；UI 移动 200–500 ms；主角揭示 600–900 ms；字母间隔 1 帧，词 60–120 ms，列表 40–80 ms；前一个完成 30–50% 时启动下一个。
- 24 fps：1 帧≈42 ms，400 ms=10 帧，750 ms=18 帧。
- 节拍：每拍帧数 = fps×60/BPM，每拍从时间算后取整，不累加取整值。拍上切，小节（4 拍）换布局。
- 文字停留 ≥ 0.3 s/词 + 0.5 s；停留期 2% 缓推保持画面活。
- 镜头曲线最软（ease-in-out-quart），物体更利落。视差 前1.0 / 中0.5 / 后0.2。
- 文字对比 ≥ 4.5:1，闪烁 ≤ 3 次/秒。

## 4. 角色动画原则（写成帧和尺寸）
- 预备（如 3 帧反向）、挤压拉伸（保体积）、重叠动作、跟随（如耳朵阻尼 0.5 比身体更松）、弧线运动。
- 手机屏尺寸观看：关键姿势夸张 10–30%。
- 每个角色必须有比例锁定行（查理王：比例/配饰/骨架链按 rig 约定，不得改）。

## 5. 审核循环（Bot E）
- 渲染静帧（如 0/24/48/72/96）或 12 帧联系表 → 写带帧号意见 → 只改变化部分 → 重渲。
- 工具：洋葱皮（间距看缓动）、速度曲线（直线=线性，尖角=硬起停）、问题帧前后两帧对比。
- 每轮只给 1–2 条意见；感受翻译成数字：
  - “更有冲击力”：scale 1.0→1.08→1.0，6 帧，峰值在拍上。
  - “更高级”：入场 ease-out-quint，弹簧 0.8，文字不过冲。
  - “拖沓”：每个停留减 1 拍（120 BPM@24fps = 12 帧）。
  - “太乱”：同时只一个主动作，其余晚 150 ms、行程 60%。
  - “像 AI”：点名默认样式，加入禁用清单，重渲。
- 记录每条修改意见（收据），用于 Bot F 偏好记忆。

## 6. 引擎选择
- <10 s 单想法：纯 HTML/Canvas + Playwright 截帧 + FFmpeg。
- 系列/模板/数据驱动/配音对齐：Remotion（本项目默认）。
- GSAP 时间线思维：HyperFrames。3D：Three.js。
- 在 Remotion 内优先用 useCurrentFrame + interpolate/spring，避免叠一套独立时钟（如 GSAP 自走时间）。

## 7. 声音（代码合成）

### 适用
- 短片 / Logo / 吉祥物短剧，需要「每个音效刚好砸在画面事件上」。
- 没有现成音效库，或版权要干净（全部合成、无采样）。
- 已经写好画面时间线，声音要跟同一条 `t` 对齐。

### 不适用 / 别硬上
- 需要人声、对白、真实乐器演奏、环境实录：改用录音或素材库。
- 超过约 30 s 的复杂混音：Web Audio 离线合成能做，但调试成本陡增，优先用 DAW。
- 只做静音草稿迭代：先不要写声音，等画面节拍锁死再加（与 Birthday Pack 顺序一致）。

### 合同
- OfflineAudioContext / Web Audio，48 kHz 立体声 WAV；无采样、无人声、无台词（除非任务另开）。
- 与画面共用同一条时间线；**每个命中峰值比对应画面事件晚 1 帧（≈17 ms @60fps）**，让观众觉得声音被画面引起。
- 响度目标约 **-14 LUFS**；真峰值 **WAV < -2 dBTP**，且必须在 **编码后的 AAC/MP4 上复测**（AAC 会冒峰）。
- 限幅器单次压限 **≤ 3 dB**；若某个单音触发限幅器大削峰，先降该音 3–6 dB，再归一化，不要靠限幅器硬压。
- 用 ffmpeg / 波形图核对同步与响度，不靠听感拍板。

### 提示词块写法
1. 总规格（采样率、时长、LUFS、峰值、晚 1 帧规则）。
2. 按 BEATS 分段：夜里底噪 → 开门/脚步 → CLICK → 派对 → 许愿近乎无声 → 吹灭 → 彩纸与短旋律。
3. 一句气质约束（如「温暖、可爱、干净；起音柔和，无刺耳高频」）。
4. 修片同画面：写「哪个音高了几 dB、降几 dB」，并报出修后 LUFS / true peak / 限幅器最大增益削减。

### 导出
- 画幅先定：16:9 1920×1080 / 1:1 1080 / 4:5 1080×1350 / 9:16 1080×1920。
- GIF：全片单调色板；24 fps 延时按 40,40,40,40,40,50 ms 循环防漂移；X 的 GIF 上限 350 帧。
- 先保证**静音版也成立**，再叠声音。

## 8. 角色短片（来源：Motion Lab「Birthday Surprise」Prompt Pack）
- 提示词分块：BRAND（角色/道具/配色，唯一要换的块，其余只引用名字）→ FORMAT → LOOK → BEATS（按秒写故事）→ CAMERA → CHECKS。283 词 + 4 轮画面修正 + 2 轮声音修正。
- 角色用像素网格定义（尺寸、部件坐标、hex 色），配饰为独立图层，四肢刚性、保持原始长度（禁止“橡皮手臂”）。
- 光讲故事：一个连续镜头靠换光分章（月光→开灯→烛光→暗→派对），而不是换机位。
- 延迟反应（delayed take）：先甩镜到原因，再甩回角色，冻住约 0.5 s 再反应。
- 物理（彩纸/飘带/领带）初始化时模拟一次，之后按 t 采样，保持“纯函数”。
- CHECKS 行最出效果：在场景光下测量角色品牌色（不对就调反照率直到读数一致）、每个节拍前后看 5 帧、检查穿模。
- 修正意见写法：看到什么 + 想要什么 + 具体数字/时间（如“蛋糕 7.9 s 前留在厨房，9.5 s 到地毯，9.74 s 放下”）。
- 高质量渲染与 16 次采样 → 见 §9。
- 声音合同与适用场景 → 见 §7。

## 9. 高质量渲染与运动模糊（16 次子采样）

### 适用
- **终版出片**：角色短片、Liquid Chrome 类 Demo、需要电影感运动模糊 / 浅景深的成片。
- 画面里有快速运动（甩镜、落体、彩纸）且静帧锐利、动起来发硬时。
- 渐变 / 金属面出现色带（banding），需要颗粒 + 抖色压纹。

### 不适用 / 跳过
- **迭代期与修片循环**：用 `?t=` 出静帧 / 联系表即可；16 采样会把单帧时间放大一个数量级。
- 纯静止构图、或画风本身要「硬切无模糊」（粗线速写、像素体素眨眼那种一格一格跳）。
- 本机 GPU 不可用、且时间紧：可先 1× 无采样出片，终版再开。
- Liquid Chrome 这类**慢速有机形变**：可只开抗锯齿亚像素采样，不必开满 0.45 帧快门（避免把轮廓糊成一团）。

### 步骤（Birthday Pack「Render it smooth」）
1. `?t=` 冻结，禁止播放时钟。
2. Headless Chrome **GPU** 按 **2×** 分辨率截帧（如 3840×2160 → 最终 1920×1080）。Windows 本机注意强制高性能 GPU（`--force_high_performance_gpu`），避免落到核显。
3. 每帧内部 **16 个样本**在 float / 线性光下平均：
   - 时间在 **0.45 帧快门**内抖动 → 运动模糊；
   - 镜头光圈上抖动 → 景深；
   - 亚像素偏移 → 抗锯齿。
4. 色调映射 → 线性光 **Lanczos** 下采样到目标分辨率 → 加一点颗粒与抖色。
5. 原始帧分块无损进 ffmpeg → H.264 High、60 fps、约 25 Mbps；WAV 混为 AAC。

### 验收
- 快速运动处有自然拖影，静止物体保持清晰。
- 金属 / 天空无色带；编码后真峰值仍达标（见 §7）。
- 循环片：第 0 帧与第 N−1 帧在采样后仍无缝（相位整数圈）。

## 10. 拉伸与步态约束（插画风角色）

### 适用
- 侧面走路 / 跑、蹲下放物、挥手等**关节运动**的插画角色（猫、狗、吉祥物）。
- 用网格变形（mesh deform）+ 骨骼，而不是图生视频。

### 不适用
- 体素 / 像素刚体角色（Birthday 的 HERO）：四肢**保持原始长度**，禁止橡皮手臂；用蹲、倾、换姿势解决问题。
- 纸片人 / 木偶戏：主要靠铰链旋转 + 关节重叠，不做皮肤拉伸。
- 照片级写实毛发：超出纯 2D 代码路线，改 3D 或图生视频。

### 提示词里必须写成数字的项
- **RIG**：骨链、每腿节数、关节两侧 ≥3 行网格、权重 50/50 跨 2 行、关节重叠 ≥8% 长度。
- **GAIT**（若走路）：步周期秒数、同侧/左右相位差、着地占比、爪尖抬高 ≤ 身高%、落脚瞬间速度 0（禁滑步）、身体前进 vs 地面卷动。
- **STRETCH 硬上限**：边长变化 ≤±12%、面积 ≤±10%（保体积）；二次运动滞后帧数与摆幅。
- **BAN**：膝盖反折、穿模、关节橡皮管弯曲、用拉长手臂够到远处物体（改动作或道具）。
- **CHECKS**：循环首尾像素一致；联系表标爪尖着地点共线；网格叠图最大拉伸标红，超限不合格。
