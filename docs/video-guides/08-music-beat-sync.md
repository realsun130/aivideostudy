# Guide Book 08：音乐卡点 / 音频可视化

画面切换和动作对准音乐节拍；或者让图形直接随音频频谱跳动（音频可视化、播客音频图）。

## 一、适用场景
- 卡点混剪、产品快闪、歌词视频、活动预告。
- 播客或音乐的音频可视化（波形、频谱柱）。

## 二、不适用
- 不知道 BPM、节奏不稳定的音乐（现场录音、自由节奏）：只能手动标点，自动网格会错。
- 有版权限制的音乐：先确认授权。

## 三、实施流程
1. 确定 BPM 和第一拍的偏移（用音频软件或分析工具测出）。
2. 生成节拍网格：第 n 拍的帧 = `round(偏移帧 + n × fps × 60 / BPM)`，每一拍都从时间重新算，不累加取整值（ML §3）。
3. 写剪辑表：哪几拍切、每 4 拍（一小节）换布局（ML §3）。
4. 动作的“重音帧”放在拍点上，预备动作提前若干帧开始。
5. 频谱类：用 `visualizeAudio()` 直接取每帧频率数据（`audio-visualization.md`）。
6. 出带拍号角标的预览，逐段对拍。

## 四、技术要点
- 音频：`<Audio>`（`remotion-markup/audio.md`）；可视化需要 `@remotion/media-utils`，用 `useWindowedAudioData()` + `visualizeAudio()`（`audio-visualization.md`，文件里有频谱柱、波形和低音驱动效果）。
- 节拍网格做成一个纯函数 `beatFrame(n)`，所有组件共用。
- 场景按拍切：`TransitionSeries`，每个 `durationInFrames` = 两个拍点帧之差。
- 冲击效果：scale 脉冲、闪白；注意闪烁上限。
- 快速运动多：终版开运动模糊（`motion-blur.md`）。

## 五、时间缓动与叙事
| 项 | 数字 | 来源 |
|---|---|---|
| 每拍帧数 | fps × 60 / BPM，每拍从时间算后取整 | ML §3 |
| 剪辑 | 拍上切，每 4 拍换布局 | ML §3 |
| 冲击感 | scale 1.0→1.08→1.0，6 帧，峰值在拍上 | ML §5 |
| “拖沓” | 每个停留减 1 拍（120 BPM @24fps = 12 帧） | ML §5 |
| 性格 | 有活力：100–250 ms，ease-out-expo，回弹 15–30% | MDS `SKILL.md` |
| 闪烁 | ≤ 3 次/秒 | ML §3 |
| 响度 | 约 −14 LUFS，成品真峰值 < −2 dBTP | ML §7 |

叙事：跟着音乐的段落走（前奏铺垫 → 主歌 → 副歌高潮），高潮段动作最大、切得最密；不要每一拍都切，会让人疲劳。

## 六、验收清单
- [ ] 开头、中间、结尾各抽一个拍点核对，误差 ≤ 1 帧（检查是否累积漂移）。
- [ ] 闪白、闪烁不超过 3 次/秒。
- [ ] 成品 MP4 上复测响度和真峰值。
- [ ] 换一首同 BPM 的曲子，网格只改两个参数就能用。
