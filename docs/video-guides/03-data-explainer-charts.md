# Guide Book 03：数据讲解 / 动态图表

用柱状图、折线图、数字滚动、对比卡讲清一个结论。数字是变量，不是烤死的像素。

## 一、适用场景
- 年报、周报、增长复盘、调研结果、产品指标发布。
- 数据会更新、要定期重出（同一模板换数据）。
- 同一个数值要同时驱动图表、标题和字幕（FR：“能组合”）。

## 二、不适用
- 数据还没核对：FR 的头号错误，“做得越好看，错误越有说服力”。
- 要交互探索的数据：做网页仪表盘，不做视频。
- 一屏塞十几条序列：先删减，视频里一屏只讲一个结论。

## 三、实施流程（FR 的数据间 → 动效间 → 剪辑间）
1. **先核对数据**：每个数字都带来源（FR：每张图附上生成它的查询）。把数据存成 JSON，放在 `public/` 或作为 props。
2. **写结论稿，留空位**：先写“这段要证明什么”，在需要图的位置标 `[图：xx]`（FR 第 3 步）。
3. 每个空位设计一张图：图表类型、高亮哪一根、对比基准。
4. 搭模板：数据经 Zod schema 进组件（`parameters.md`），总时长用 `calculateMetadata` 按条目数算。
5. 动画顺序：坐标轴 → 数据出现 → 高亮结论 → 标注文字。
6. 静帧检查：最终帧的数值必须和数据完全一致。
7. 用话导演（“柱子晚半拍”“线画慢一点”），每句改一行。

## 四、技术要点
- 图表用 SVG 或 div 自己画，所有长度 = `interpolate(frame, [起, 止], [0, 值])`，`extrapolateRight: "clamp"`（`timing.md`），避免越界。
- 数字滚动：显示值 = 当前插值结果取整并格式化；最后一帧强制等于真实值。
- 折线描出：`stroke-dasharray` + `stroke-dashoffset`。
- 强调某个数据：`text-highlights.md` 的 `<Circle>` / `<Highlight>`。
- 多场景：每个图一个组件、一个文件，用 `TransitionSeries` 串起来（`multi-scene-video.md`）。
- 有配音时：配音决定每段时长，见 05。
- 不要用系统时间、`Math.random()` 生成假数据（ML §1）。

## 五、时间缓动与叙事
| 项 | 数字 | 来源 |
|---|---|---|
| 数据可视化错开（Wave） | 30–60 ms/项，总 < 500 ms | MDS `reference/timing-easing-tables.md` |
| 列表错开 | 40–80 ms | ML §3 |
| 性格 | 商务：200–400 ms，(0.2,0,0,1)，回弹 0–3% | MDS `SKILL.md` |
| 柱子生长 | ease-out；不许线性做空间运动 | MDS 质量规则 |
| 进度类 | 线性只用于进度条、旋转 | ML §3 / MDS |
| 结论停留 | ≥ 0.3 s/词 + 0.5 s | ML §3 |
| 每个图的完整周期 | 4–8 s（**起始值，需调**） | — |

叙事：一屏一个结论，先给对比基准再给结果。三层运动：主（数据）、次（标签和网格线跟随）、环境（背景极轻微的变化）。超过 3 个元素时同时动的不超过 1/3。

## 六、验收清单
- [ ] 最后一帧所有数值与源数据逐一一致，单位、小数位正确。
- [ ] 每个数字能追溯到来源（JSON 里带 source 字段）。
- [ ] 坐标轴从 0 开始，或明确标注截断。
- [ ] 结论文字停留够读。
- [ ] 换一组极端数据（很大、很小、负数）也不溢出、不穿版。
