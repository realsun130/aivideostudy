# Guide Book 06：角色短片

一个或几个角色通过表演讲一个小故事。角色是用代码构造出来的（坐标、部件、骨骼），不是从图片里切出来的。

## 一、适用场景
- 吉祥物短剧、节日祝福片、品牌故事、表情包短片。
- 角色可以写成几何部件：像素 / 体素、纸片 / 剪纸、扁平矢量。

## 二、不适用
- 照片级写实角色、毛发随肌肉起伏：超出纯 2D 代码路线，用 3D 或图生视频（ML §10）。
- 需要大量对白口型、复杂表演：成本极高，先做无对白版。
- 只有一张成品插画、想切开来动：切图得到的部件不干净，优先“部件先行”重画（ML §8）。

## 三、实施流程（BDAY 六块提示词）
1. **BRAND**：角色用网格或部件定义（尺寸、部件坐标、hex 色），配饰为独立图层；道具、房间、配色都在这里定义一次。
2. **FORMAT**：引擎、画幅、帧率、时长；`renderAt(t)` 精确画出时刻 t，随机带种子。
3. **LOOK**：画风、表演词汇（挤压拉伸、眨眼）、哪里允许发光（禁止项）。
4. **BEATS**：按秒写故事，只写“什么时间发生什么”。
5. **CAMERA**：每个节拍给镜头一项任务。
6. **CHECKS**：测角色品牌色、每个节拍前后看 5 帧、不许穿模。
7. 首版之后按“在哪一帧、看到什么、原因、改成多少”修 2–4 轮（ML §0、§8）。
8. 画面锁定后再做声音（ML §7）。
9. 终版开 2× + 16 次采样（ML §9），或 Remotion 的 `HtmlInCanvasMotionBlur`。

## 四、技术要点
- 引擎：2D 用 Remotion + SVG / Canvas；3D 体素用 three.js（RS `remotion-markup/3d.md`），同样由帧号驱动。
- 物理（彩纸、飘带）：初始化时用种子模拟一次，之后按 t 查表（BDAY 公式 2）。
- 骨骼：父子层级 transform，每个关节一个旋转值 = f(frame)。插画风关节运动的网格和拉伸约束见 ML §10。
- 表情：嘴、眼睛作为可替换的部件（替换而不是变形），一格一格跳。
- 运动模糊：`remotion-markup/motion-blur.md`（`samples` 默认 8、最多 64，`shutterAngle` 默认 180）。
- 声音：代码合成按 ML §7，或用 `sfx.md` 现成音效。

## 五、时间缓动与叙事
| 项 | 数字 | 来源 |
|---|---|---|
| 预备动作 | 如 3 帧反向 | ML §4 |
| 手机观看 | 关键姿势夸张 10–30% | ML §4 |
| 次要动作 | 幅度 50–70%，晚 100–200 ms | ML §2 |
| 环境动作 | < 5%，慢正弦，不停 | ML §2 |
| 延迟反应 | 甩到原因 → 甩回 → 冻住约 0.5 s → 再反应 | BDAY / ML §8 |
| 声音晚画面 | 1 帧 | BDAY / ML §7 |
| 拉伸上限（网格角色） | 边长 ±12%，面积 ±10% | ML §10（起始值） |
| 情绪：快乐 | 向上弧线，ease-out-back | MDS 情绪表 |
| 情绪：悲伤 | 下垂曲线，cubic ease-in-out，较慢 | MDS 情绪表 |
| 情绪：惊讶 | 向外扩张，ease-out-expo | MDS 情绪表 |

注意：MDS 情绪表的时长（200–1200 ms）是界面元素的；**角色的一个表演节拍通常要 1–3 秒**（**起始值，需调**），只借它的方向、路径和曲线。

叙事：用光讲故事——一个连续镜头靠换光分章，而不是换机位（BDAY 公式 1）；反应慢半拍（BDAY 公式 5）。

## 六、验收清单
- [ ] 每个节拍前后 5 帧都看过（BDAY CHECKS）。
- [ ] 场景光下角色品牌色实测等于 hex。
- [ ] 不穿模；四肢不被拉长作弊（BDAY 第 4 轮修改）。
- [ ] 角色比例在整片里不漂移（ML §4 比例锁定）。
- [ ] 静音版也成立；加声音后响度和峰值在成品上复测。
