# Guide Book 11：国风水墨风景短片（可选内容线 ⚠️ 待测试）

纯代码画出来、会「呼吸」的水墨山水，几幅画一镜接一镜，配代码合成的古筝、箫、颂钵。竖屏 9:16 1080×1920，面向小红书、抖音、B站。没有角色，靠画面、运镜、转场和声音取胜。

> 状态：可选内容线，尚未跑通一支成片。参考实现是 [Leonxlnx/shanshui](https://github.com/Leonxlnx/shanshui)（MIT，下称 **SS**）：10 幅画、60 s、横屏 16:9，不加载任何图片、字体或音频素材。

## 一、适用场景
- 节气、季节、诗词意境短片（一首诗配一幅或几幅画）；一天或一年在同一位画师笔下流转。
- 账号的氛围片、片头、长期系列（每期一个节气或一处名山）。
- 想要「静帧截图就能当壁纸」的内容：每幅画本身要能单独成立。

## 二、不适用
- 需要角色表演、对白：SS 没有角色，这条线也不做角色；角色走 06。
- 需要写实风景、真实地点辨认度：这是写意画，不是地图或实拍（地理讲解走 09）。
- 想一周出一支：首支的笔触库（松、石、山、雾、水、鹤）要先建，成本集中在前期，后续才能复用。

## 三、实施流程
1. **选题与时钟**：先定 BPM 和小节，每幅画占 2 小节；SS 是 80 BPM、一小节 3 s、每幅 6 s。竖屏短片建议 5–8 幅、30–50 s（**起始值，需调**）。时钟文件同时给画面和音乐用（见 [cinematography-filmgraph.md](../cinematography-filmgraph.md)「2.5D 视差镜头」§4）。
2. **参考与 Style Bible**：每幅画找一张参考图（公有领域或自有，只用于对比，不进成片），按 [STYLE_AND_SHOT_SUMMARY.md](../STYLE_AND_SHOT_SUMMARY.md)「Style Bible 编写指南」实测纸色、墨色、亮度分位、朱红占比，写元素坐标表和「看起来假」清单。
3. **竖屏构图**：横幅山水改成「立轴」：上留天、中为主峰、下为水与近景；近景主体（松、崖）贴一侧边缘出画。不要把横版画缩进竖框。
4. **分层**：每幅画拆成近 / 中 / 远 / 天四类卡片放在不同深度（cinematography §1），写清每张卡片的出血量（cinematography §2）。
5. **静帧先审**：每幅画在 t = 2–4 s 出一张静帧 + 和参考的 side / crop 对比，用户批准后再做动效（项目规则：先静帧后动效）。
6. **动效与转场**：每幅画按 element_motion 数字动起来；转场全部由画里的元素带出（雾、云、水雾、落叶、日轮），以小节线为中心。
7. **声音**：代码合成配乐，按同一时钟写音符和提示点（ML §7）。
8. **出片与查错**：成片 2 次子采样运动模糊；跑 `tools/forensics.py`，再按验收清单过。

## 四、技术要点
- **从 SS 借这些**：
  | 借什么 | SS 怎么做 | 我们怎么用 |
  |---|---|---|
  | 墨晕开场 | 白纸上最深的墨先出现，从两个种子点带着湿边晕开，3.0 s 画完一幅 | 每期固定开场，做成账号记忆点 |
  | 蒸发收尾 + 印章 | 浅墨先蒸发、最深的墨最后消失，回到白纸，只留印章（盖印 56.7 s，蒸发 1.8 s） | 结尾落版：印章 = 账号名或期号 |
  | 画师词汇（分层库） | 松（扭曲树干、近水平枝、针叶团）、山石（顶缘干笔、皴法竖纹、苔点）、远山剪影、雾、云海、水与倒影、瀑布、亭台、鹤、落叶、雪 | 先建笔触库，按「近景最黑最锐、远景最淡最虚」组合 |
  | 质感处理 | 静态笔触烘焙成纹理，再过一遍「墨处理」：边缘淤积、颗粒、晕开 | 见 cinematography §6，去电脑矢量感 |
  | 合成配乐 | 古筝（Karplus-Strong 拨弦，带推弦、颤音、轮指、刮奏、泛音）、箫（带气声）、颂钵（拍频泛音）、低音持续音、风声水声环境层；48 kHz，-14 LUFS | 不用采样，版权干净；按我们的声音合同复测成片真峰值（ML §7） |
- 动作数字（SS STYLE.md，原片短边 1080，竖屏水平量可照抄）：雾 5–25 px/s；松竹枝梢 1–5 px、0.15–0.35 Hz；鹤扇翅 0.8–1.1 Hz、横穿 40–90 px/s；落叶 40–110 px/s；雪 20–60 px/s；瀑布 150–400 px/s；相机 8–35 px/s。
- 色彩：纸永远在（不纯白、不平涂），近景要有真黑，朱红 < 2% 像素；禁辉光、镜头光效、高饱和色（SS「看起来假」清单）。
- 每帧纯函数、随机带种子（ML §1、§12）；会动的元素每帧按 t 画，不动的只烘焙一次。

## 五、时间缓动与叙事
| 项 | 数字 | 来源 |
|---|---|---|
| 节拍 | 80 BPM，一拍 0.75 s（24 fps = 18 帧），一小节 3 s（72 帧） | SS timeline.js |
| 每幅画 | 2 小节 = 6 s | SS FILM.md |
| 转场 | 1.6–2.2 s，中心在小节线上；开场墨晕 3.0 s，收尾蒸发 1.8 s | SS FILM.md |
| 每镜自身运镜 | 慢推 / 横移 8–35 px/s，dolly ≤ 0.08 | SS STYLE.md |
| 运动模糊 | 成片 2 子采样，快门 0.5 帧 | SS README |

叙事：一口气的「流转」——时间（晨→午→暮→夜）或季节（春竹→秋枫→冬雪）单向推进，全片一个最强时刻（SS 放在第 5 幅红瀑布，约 24 s）。文字只在开头或结尾出现一次（诗句或节气名），不在画面运动中滚字幕。

## 六、验收清单
- [ ] 每幅画静帧放在参考图旁，像同一位画师画的（side + crop 对比已附）。
- [ ] 实测纸色、墨色、亮度分位在 Style Bible 区间内；朱红 < 2%。
- [ ] 任何转场都没有露出卡片边缘（转场首、中、末帧联系表已看）。
- [ ] 每幅画在可见窗口内一直在动，没有「静帧 + 淡入淡出」的幻灯片感。
- [ ] 转场都是画里的元素带出来的，中心在小节线上。
- [ ] `tools/forensics.py` 转场外 pop = 0，其余项逐条看过。
- [ ] 配乐全合成、无采样；成片 -14 LUFS、真峰值达标（编码后复测）。
- [ ] 手机 360 px 宽预览下，近景黑与留白对比仍清楚。
